🚀 COMO COMEÇAR
═══════════════════════════════════════════════════════════════════

1️⃣ INSTALAÇÃO
   cd src/frontend/Clima.Cep.App
   npm install

2️⃣ DESENVOLVIMENTO
   npm start
   → Abre em http://localhost:3000

3️⃣ BUILD
   npm run build
   → Gera pasta /build

4️⃣ DOCKER
   docker-compose up -d
   → Inicia todos os serviços
